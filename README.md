## 1.プロジェクト概要

プログラミングに特化した学習記録サイト「StudyLog」を作成しました。  
プログラミング学習をより快適に継続できるようなアプリケーションを作りたいと思い、作成しました。  
今自分がどの言語をどれくらい勉強できているかがグラフで一目で確認できます。  
また、学習記録時にコードも保存でき、あとから見返すことができます。

## 3.機能・特徴
機能  
・ユーザー認証（新規登録、ログイン、ログアウト）  
・学習時間、コードの記録  
・学習記録の編集、削除、検索  
・任意の科目の追加（バックエンド、フロントエンド、その他の3種類に分類される）  
・勉強時間に応じてグラフ、レベルが表示される    

特徴  
・すでに記述しましたが、科目別に通算の学習時間が縦棒グラフで表示されます。  
　科目ごとに色が違うので、どの科目がどれくらい勉強できているかが一目で分かります。  
　なお、グラフの色は10色まで用意しているので、10科目までは科目ごとに別の色が表示されます。  

・トータルの学習時間に応じてレベルを設定しています。  
　ヘッダーに現在のレベル、経験値バー、レベルアップに必要な経験値（学習時間）を表示しています。  
 
・学習記録を科目、またはコードのタイトルで検索できます。  
　両方入力するとAND検索になります。  
　検索をする際、リアルタイムでフィルタがかかります。
